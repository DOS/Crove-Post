Crove x DOS.ID x DOSClaw

Tạo và kết nối Crove ngay trong agent

Người dùng không cần vào Crove để tạo account hoặc sao chép API key. Người dùng xác thực bằng DOS.ID, còn agent hoạt động bằng credential máy với máy và API key Crove được lưu mã hóa.

Không sửa Postiz

Dùng route đăng ký Generic OAuth, session, organization và API key có sẵn của image upstream.

Không dùng chung account

Mỗi DOS.ID được ánh xạ vào đúng Crove user và organization của họ bằng stable sub.

Agent không giả làm người

DOS.AI gửi assertion có chữ ký. Agent không giữ password, refresh token hoặc browser session của DOS.ID.

Luồng hoạt động

1
Người dùng ra lệnh
Agent nhận yêu cầu kết nối Crove và hiển thị xác nhận rõ ràng.
2
DOS.AI phát hành assertion
Assertion có chữ ký, gắn với DOS.ID sub, email, agent, audience, scope, thời hạn tối đa 60 giây và nonce chống replay.
3
Crove tạo token một lần
sso.crove.com/v1/provision xác minh assertion rồi tạo token crv_prv_ chỉ dùng một lần ở UserInfo.
4
Postiz tự provision dữ liệu của nó
Crove gọi route đăng ký Generic OAuth có sẵn. Postiz tự tạo hoặc tìm user, organization, membership, session và API key.
5
DOS.AI lưu credential
Crove trả API key đúng organization một lần. DOS.AI mã hóa key và bật bộ MCP Marketing hiện có.
6
Web và agent dùng chung identity
Người dùng login Crove bằng DOS.ID sẽ vào đúng account mà agent đã tạo.

Idempotency và nhiều organization

Provisioning lặp lại với cùng DOS.ID sub phải trả về cùng Postiz user, không tạo duplicate. Khi user chỉ có một organization, Crove tự chọn. Khi có nhiều organization mà chưa có mapping, DOS.AI yêu cầu user chọn ngay trong DOS.AI, không bắt mở dashboard Crove.

Disconnect và revoke

Disconnect thông thường chỉ xóa credential mã hóa khỏi DOS.AI. Account, channel và post trên Crove vẫn còn. API key Postiz là key cấp organization, nên rotate key sẽ làm hỏng mọi client API, MCP và CLI khác. Rotate chỉ được thực hiện bằng xác nhận tác động cao riêng.

Social OAuth vẫn cần người dùng

Provisioning account không thể bỏ qua consent của Facebook, TikTok, LinkedIn và các social provider. Luồng consent có thể mở bên trong DOS.AI, nhưng vẫn phải do người dùng xác nhận.

Kết luận branding

Image Postiz chính thức không có env để white-label toàn app. Hai env NEXT_PUBLIC_POSTIZ_OAUTH_DISPLAY_NAME và NEXT_PUBLIC_POSTIZ_OAUTH_LOGO_URL chỉ đổi nút DOS.ID, và Crove hiện đã set cả hai.
